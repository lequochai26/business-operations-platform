# Danh mục component dùng chung

**Tóm tắt.** Danh sách các component giao diện dùng chung giữa các màn hình. Cần tra file này **trước** khi thiết kế component mới.

- Component cơ bản như nút, ô nhập, thẻ, thông báo và badge cơ bản nằm trong `docs/design/ui-style.md`.
- Mockup dùng các component cơ bản qua `docs/design/ui/mockup-base.css`.

**Danh sách component**
- [AppNav](app-nav.md) (`<mio-app-nav>`): thanh điều hướng trái theo vai trò, kèm khối tài khoản có Đổi mật khẩu và Đăng xuất.
- [PasswordField](password-field.md) (`<mio-password-field>`): ô nhập mật khẩu có nút hiện/ẩn ký tự.
