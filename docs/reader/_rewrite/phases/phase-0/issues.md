# Sổ vấn đề – Giai đoạn 0

**Tóm tắt.** Sổ ghi các vấn đề của giai đoạn 0, mỗi vấn đề một mục.

**Cách ghi**
- Mã vấn đề có dạng `P0-ISS-<nnn>`, tăng dần và không tái sử dụng.
- Không xoá mục nào. Vấn đề không sửa thì đặt trạng thái `không sửa` kèm lý do.
