# Danh mục component dùng chung

Tra file này **trước** khi thiết kế component mới. Component cơ bản (nút, ô nhập, thẻ, thông báo, badge cơ bản) nằm trong `docs/design/ui-style.md`; mockup dùng chúng qua `docs/design/ui/mockup-base.css`.

- [AppNav](app-nav.md) – `<mio-app-nav>` – thanh điều hướng trái theo vai trò, kèm khối tài khoản (Đổi mật khẩu, Đăng xuất)
- [PasswordField](password-field.md) – `<mio-password-field>` – ô nhập mật khẩu có nút hiện/ẩn ký tự
